# v1.2 Three.js ビジュアル設計

## 今回の方向

既存ルールを保ち、人物のいない、木のテーブルと立体的なスイカを主役にした画面へ置換。参照画像の斜め上の構図、縞模様、自然光、輪ゴムの重なりを手続き的に実装した。人物・顔面衝突・声の演出は使用しない。

## シーン

- PerspectiveCamera：35度の画角、約36度の俯瞰。縦画面は中央、短い横画面はスイカを左、操作盤を右へ寄せる。
- 照明：暖かい主光源、半球光、弱い補助光。小さなRoomEnvironmentをPMREMで反射に使用。
- スイカ：上側3セクター＋下側。半径関数は中央へのガウス状の変形で、肩と底を維持する。頂点と法線は本数変更時だけ更新。上下面のUVと法線を共有する計算で継ぎ目を抑える。
- 皮：1024×512の縞・まだら・微細凹凸を自作。MeshPhysicalMaterialの控えめなclearcoatで艶を出す。
- 輪ゴム：最大70本のInstancedMesh、48分割の軽いトーラス。幅・傾斜・色の揺らぎ。新しい1本だけが伸びて縮み、果実もわずかに揺れる。
- 背景：木のテーブル、無地の壁、予備輪ゴムの小皿。主役を妨げる人物や装飾は置かない。
- 果肉：自作の赤い繊維模様、薄い白い皮、種。上下の断面と上側の破断面は破裂時のみ見える。

## 破裂の方向

初期実装前に観察した添付動画では、19.61〜19.68秒付近で上部が一気に上昇し、下部の赤い断面はテーブル上に残った。今回もその力の方向を維持する。動画にいた人物の再現は今回の仕様から除外。

240msのきしみの後、上側と果汁を主に上方向へ射出。140msのヒットストップ。最初は上側がまとまって上昇し、その後3個の不均一な姿勢の破片に分かれてテーブルに落ちる。下側はその場に残る。下側の縁には不規則な欠けを作り、断面を窪ませ、ちぎれた果肉を残す。平らな円盤の切り口は使用しない。

上側の破片、解放された輪ゴム、小さな果肉・種・皮は、1/120秒刻みの簡易剛体計算で重力・回転・接地点のトルク・反発・摩擦を適用。果肉の反発係数は0.12、輪ゴムは0.58。輪ゴムは張力を失うと縮み、回りながら跳ねて滑る。汁の跡は飛沫が床へ接触した位置に発生する。結果表示後も約1.6秒だけ物体を落ち着かせ、再挑戦では直ちに破棄・初期化する。

このソルバーは静止したテーブル平面への接触を扱う。フルソフトボディ、流体解析、破片同士の相互衝突は行わない。赤いものはすべてスイカ。

## コア体験

`src/game.ts` はv1.1から変更なし。

SAFE幅は `max(0.065, 0.28 - bands * 0.0043)`。針の速度は `min(1.35, 0.64 + bands * 0.014)`。本数30でSAFE約15%、50で6.5%。中央34%がPERFECT。

新しいスイカの耐久は40〜70。本数と隠しダメージを加算し、限界で必ず破裂する。外観のくびれは本数だけで決め、残り耐久は漏らさない。MISSでも輪ゴムを加える。0.29秒の入力間隔と破裂中のロックも維持。

## DOM UI

上部にタイトル、小さなBEST、現在本数。下部の半透明パネルに半円メーターと1個の操作ボタン。SAFE中央の明るい帯と白い針を見て押す。短い判定、本数のポップ、ボタンの押し込みが入力に追従する。

結果は操作盤だけを切り替え、破裂後の果実を見せたまま再挑戦できる。フォントはローカルOutfit。320pxの縦画面では余白と計器を縮め、横画面は左右配置。端末フレームは描かない。

## ライフサイクルと負荷

- 単一requestAnimationFrame。DOMはイベント時だけ更新。背景タブではゲーム・描画・音を停止。
- 計器は軽い2D Canvas。3Dは追加後約0.42秒・きしみ・破裂・サイズ変更時に更新し、静止中は再描画しない。
- スマホDPR最大1.5、PC最大1.75。負荷継続時は1まで段階的に下げ、必要なら3Dだけ約30fpsに制限。
- 飛散は4種類のInstancedMeshで100個まで、果汁跡は20個まで。reduced-motionでは粒子を減らし、シェイク・細かな揺れ・UIポップを止める。
- ゲーム用timerは使わず、再挑戦で粒子とポーズを初期化。破裂用シェーダーを開始前にコンパイル。
- GPUコンテキスト喪失はゲームを一時停止。復帰時はPMREMを再作成し、状態を維持する。
- 破棄時はResizeObserver、イベント、アニメーション、Three.jsのジオメトリ・テクスチャ・マテリアル・InstancedMesh・反射マップ・影を解放。
- Web Audioは1個のAudioContext、再利用するノイズバッファ、終了時に切断する音声ノード。人物の声は果汁の飛散音に置換。
