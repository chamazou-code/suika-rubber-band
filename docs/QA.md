# v1 検証記録

2026-09-09。ローカルの実装・ビルドの検証と、外部公開状態を分けて記録する。

## 合格済み

- 純粋なルールのテスト8件。
- 全PERFECTで個体耐久40〜70のすべてが規定本数で必ず破裂。
- 500個体の各入力でSAFEが毎回移動し、画面端を避けることを確認。
- PERFECT / GOOD / MISS、すべて1本追加。コンボと累積ダメージ。
- 連打ロック、破裂中の入力ロック、1回限りのburst / hit / resultイベント。
- 再挑戦時の初期化、NaN / Infinity / 負のdt、破損・禁止されたストレージ。
- Chrome本体を用いたデスクトップとAndroid設定、WebKitによるデスクトップとiPhone設定で、計12件のE2Eテストが合格。
- 320×568、390×844、844×390における幅超過なし、操作ボタンの表示。
- タップ・クリック・Space・Space長押し、ミュートによる誤入力なし。
- 開始 → 複数回入力 → 破裂 → 顔への衝突 → リザルト → 再挑戦 → リロード後BEST保存。
- reduced-motion、localStorage無効時もプレイ可能。
- ページ例外なし。Vite開発画面とProduction build成功。
- Desktop Safari本体でページ描画、開始、Spaceによる本数増加と音声再生開始を確認。

- iPhone 16 / iOS 26.4の専用SimulatorでSafari本体を開き、縦画面のレイアウト、タップ開始、輪ゴム追加を確認。

## ゲームフィール調整

メーターの描画ピクセルを読むQAプレイヤーで、実時間の3ラウンドを実行。内部耐久を参照せず、実際のUI操作だけを使用。初期設定では44本/100%/50.75秒、41本/66%/49.17秒、62本/100%/64.85秒。待ち時間を縮めるため、針の速度を `0.64 + bands * 0.014` に調整。

## 検証の限界

- Android Chromeの物理端末は未接続。AndroidについてはChromeのタッチ・端末設定による検証。
- WebKitによるiPhone設定は、iPhoneの物理端末での検証とは区別する。
- 視覚的なタイミングが主題のため、画面リーダーだけで同等にプレイできる設計ではない。操作ラベル、判定の読み上げ、フォーカス、ミュート、ズーム、reduced-motionには対応。
- 連打だけなら意図どおり早く破裂する。1ゲーム20〜60秒は、SAFEを狙って操作する場合の目安。
- サウンドは合成音。人物の声は声風のピッチ下降音で、実際の声優録音ではない。
