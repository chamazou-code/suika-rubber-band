# v1.2 Three.js 検証記録

2026-09-09。今回の3D版を対象とする。以前の2D版のSafari本体・iOS Simulator確認を、今回の実機確認として扱わない。

## ルール・物理・ブラウザ

- 単体テスト14件成功。従来の8件に加え、局所変形・表面の継ぎ目・有限な頂点値、破断面の凹凸、固定刻み物理の30/60fps一致、ヒットストップ、材質による反発差を確認。
- `src/game.ts` はv1.1から変更なし。40〜70の個体耐久、隠しダメージ、SAFE判定と移動・縮小、速度、入力間隔、BESTを維持。
- Chrome本体／Desktop WebKit／iPhone WebKit設定／Android Chrome設定でE2E合計14件成功。
- WebKitのコンテキスト喪失シミュレーション2件は明示的にskip。通常のWebGL2描画・開始・破裂・再挑戦は両WebKit設定でも確認。Chromiumの2設定ではコンテキスト喪失中の入力停止と同じ本数での復帰も成功。
- 320×568、390×844、844×390、1440×900を確認。横幅超過なし。タップ・クリック・Space、長押し、連打、破裂中ロック、ミュート誤入力、BEST保存・保存禁止、reduced-motionを検証。
- 3DのWebGL2コンテキストが有効でGLエラーがないこと、ページ例外がないことを確認。
- Production build成功。JavaScript約600KB、gzip約154KB、CSS gzip約3.4KB、Outfit約20KB。Three.jsを含む単一JSチャンクが500KBを超えるVite警告あり。外部モデル・画像・音声・HDRの追加ダウンロードはなし。

## 見た目と動き

- 人物を削除。木のテーブル、俯瞰カメラ、深緑の皮と縞、局所的なくびれ、3D輪ゴム、半円メーターを画面で確認。
- 40本時のくびれと輪ゴム束、上方向への破裂、下側の残留、果肉・種、3つの上側破片を画像記録。
- 下側の切り口は不規則に欠けた縁・窪み・残った果肉片を持つメッシュへ変更。平らな円盤を廃止。
- 輪ゴムは破裂時に解放し、縮みながら回転して飛ぶ。果肉と輪ゴムには重力・回転・反発・摩擦を適用。接地点を平均して偏った荷重による回転を計算し、片端だけで立ったまま止まる挙動を抑える。結果表示後も短時間だけ落ち着くまで進める。再挑戦で前ラウンドの物理状態をリセット。

## 3D負荷と繰り返し

`node scripts/profile-scene.mjs` の開発用独立ハーネス。390×844、端末DPR3に対して3DはDPR1.5。カメラの俯角36.19度。

- 静止状態120フレームで3D再描画0回。
- 初期20 draw calls / 21,148 triangles。70本時23 / 101,788、破裂開始45 / 102,956。数値は影の描画パスを含むThree.jsカウンター。
- 最大70本まで追加→破裂→静止を5回反復し、各回の静止後リソース数はgeometry42、texture12、program16で一定。
- 破裂0.15秒時に上側は0.67単位上昇し、下側のローカルYは0。解放輪ゴムは70本、例の2本は最終的に中心から約3.81／4.13単位移動。
- 破棄後のscene geometryは0。Three内部のカウンターはtexture1/program3が残るため「全カウンター0」とは扱わない。renderer.disposeとforceContextLossまで実行し、コンテキストを破棄。
- 固定刻み物理は1/120秒。3Dフレームが省かれても同じ時刻の状態へ進む。重い外部物理ライブラリは追加していない。

## CIの調整

最初の3D版CIではLinuxのソフトウェア描画で長いラウンドテスト4件が60秒の上限に到達。残る10件は成功した。ルールは変更せず、連打は同じDOMキーボードイベントをまとめて送り、仮想時間を50ms以下の刻みで進めることで余分な60fps描画を減らした。通常入力はPlaywrightの実入力のまま。CIも1ワーカーにして描画競合を避け、ラウンド全体のテストだけ120秒の実行枠を与える。実時間の操作・更新間隔の評価は別のQAプレイヤーで行う。

再実行は13件成功し、1440×900のDesktop Chromiumだけ破裂の描画中に120秒で時間切れ。CIのデスクトップは960×720、モバイルは同じCSS寸法でDPR1にし、ソフトウェアGPUの画素処理を削減する。WebGL描画は実際に実行し、検査項目は省略しない。1440×900と高密度モバイルの描画はローカル確認を継続。

960×720でもDesktop Chromiumの破裂後半の仮想時間コマ送りが120秒を超えるため、CIの長いラウンドテストだけ300秒を上限とする。残る13件は合格。全シーンとすべての検査を維持し、実行枠を増やす。CIと同じChromium構成のローカル実行はデスクトップ34.9秒、Android設定25.2秒で完了。これはソフトウェア描画・仮想時間・画像記録を含むテストの実行時間で、ゲーム1ラウンドの所要時間ではない。

## 残る制約

- 今回の3D版はiPhone／Android物理端末、Safari本体で未確認。モバイル・デスクトップWebKitによる確認とは区別する。古い端末の温度・電池・長時間性能は未計測。
- WebGL2が必要。利用不能時は説明と再読み込みを表示し、2D版へ自動切替はしない。
- 物理はテーブル平面への簡易剛体接触。破片同士の衝突、輪ゴムの完全なソフトボディ、流体解析は行わない。破片が互いに重なる場合がある。
- 視覚的なタイミングが主題のため、画面リーダーだけで同等に遊べる設計ではない。操作ラベル、判定読み上げ、フォーカス、ミュート、ズーム、reduced-motionには対応。
